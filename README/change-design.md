# Change the design

Open [style.css](../src/style.css) for colors, spacing, fonts, and responsive layout. For example, search for `#c8fb74` to find the bright green accent. The font imports are at the top of the file.

The page structure and section text are in [main.jsx](../src/main.jsx). The favicon is [favicon.svg](../public/favicon.svg); replace it with another SVG at the same path to update the browser tab icon. The page title and description are in [index.html](../index.html).

After making a change, check the site on a wide screen and a narrow screen, run `npm run build`, and [redeploy](./deploy-vercel.md).
