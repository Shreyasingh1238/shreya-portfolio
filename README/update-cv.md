# Replace the downloadable CV

1. Prepare your new CV as a PDF.
2. Rename it `Shreya_Singh_Resume.pdf`.
3. In VS Code, open the `public` folder and replace [the existing PDF](../public/Shreya_Singh_Resume.pdf) with your new file. Keep the filename exactly the same.
4. Start the site and click **Download CV** on the home section. Open the downloaded file to confirm it is the new version.
5. Upload your changes and redeploy your site using the [Vercel guide](./deploy-vercel.md).

Anyone visiting your site can download this file, so include only information you want to share publicly. If the browser still downloads an older copy after deployment, try a private browser window or clear its cache.
